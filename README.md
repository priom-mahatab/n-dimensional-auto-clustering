# N-Dimensional Auto-Clustering of Lidar Measurements to define Defacto Aerosol Types

- Science question: 1) Will AI-driven auto-clustering of HSRL reported quantities yield aerosol types with vertical and temporal cohesiveness? 
- Science question: 2) Will the collection of uncalibrated lidar instruments at BNF yield auto-clustered aerosol types consistent with those from the BNF HSRL?
- Science question: 3) Will the model for uncalibrated lidar yield vertically and temporally cohesive aerosol types when applied to other sites?

### Project Scope: Incorporating lidar measurements from HSRL, Ceil, MPLpol, and DL to identify auto-clustered populations and assess whether these may serve as defacto “aerosol types”. 
### Datasets:
- Dataset 1: BNF HSRL: using ASR, ldr, color ratio
- Dataset 2: Ceil, MPLpol, DL (Doppler Lidar)
